# ユメクイ 立ち絵の台本

作成日: 2026-11-13 / 作成: Claude（claude.ai）/ 確認: 安田匠

どの場面で、だれの立ち絵を、どの表情で、どこに出すかをまとめた台本。Claude Code はこれを見て立ち絵を実装する。

- **1〜3 章**：決まり。
- **4 章**：まだゲームにない場面の台本。Claude が書いた仮のセリフなので、安田が確認してから入れる。
- **5 章**：今ゲームにある全部のセリフを、場面ごとに表にしたもの。表情はパッチ 0018 で `src/scenes/story.js` と `src/scenes/mornings.js` に書き込み済み。

---

## 1. 会話の立ち絵の決まり

| 決まり | 内容 |
| --- | --- |
| 何人まで | 最大 2 人 |
| 左 | 主人公・仲間側。ハルがその場面で話すなら、ハルは左 |
| 右 | 話している相手 |
| 2 人とも相手のとき | ハルがいない場面（ミオとカナなど）は、先に話した人が右、もう 1 人が左 |
| 明るさ | 話している人は明るく、聞いている人は `brightness(0.55)` で暗く |
| 位置を決めるとき | 場面の最初。場面が終わるまで左右は動かさない |
| 表情 | セリフの 3 つ目の要素。`['カナ', 'セリフ', 'angry']`。ないときは neutral |
| 立ち絵が出ない話者 | バク、ナレーション、生徒、カイト、モモ、トメ、ケン、美術部の子、？？？、顔たち、ユメクイ |
| 夢の住人 | 審査員カナ・独奏の女王ミオ・ハルの人形は表情なしの 1 枚。右に出す |
| 消すとき | 場面が終わる（`talk()` が終わる）とき |

話者名と画像の対応は `src/data/portraits.js`（パッチ 0018 で追加）。`portraitOf('カナ', 'angry')` で `./img/chara/kana_angry.png` が返る。差分にない表情を渡すと neutral になる。

### 表情の使い分け

| 表情 | 使う場面 | 例 |
| --- | --- | --- |
| neutral | ふつうに話す。迷ったらこれ | 「……夢、か。」 |
| smile | うれしい・ほっとした・強がって笑う | リク「だいじょうぶだいじょうぶ！」 |
| angry | 強く言い返す・本音をぶつける | カナ「なんで何も言ってくれなかったの！」 |
| surprised | 驚く・気づく | ハル「リクが……？」 |
| troubled（ハル・ミオ・リク） | 困る・言えない・迷う | ハル「……まだ。」 |
| frustrated（カナ） | イライラ・くやしい | カナ「せめて相談してくれたら」 |
| cry（リク） | 本音があふれる | リク「言ったらさ、お前……」 |
| silent（ハルの父） | 黙る・話を打ち切る | 父「……もういい。部屋に行け。」 |
| sad（リクの父・ミチル・ヒカリ） | 悲しい話をする | リクの父「母さんが死んでから」 |
| cloudy（アキ先生） | 笑顔がくもる・心配 | アキ先生「月島くんのこと、心配ですよね」 |
| resolve（ミチル） | 心を決める | ミチル「……さよなら、ヒカリ。」 |
| eroded（ミチル） | 星の夢に命を使っていると分かってから | 4-3 を見る |

## 2. 戦闘中の立ち絵

| 出来事 | 出す絵 | 位置と動き |
| --- | --- | --- |
| 本音の選択肢（「カナの本音は？」など） | 夢主の `*_profile`（横顔） | 左に、高さいっぱい。少し透かす。選んだら消す |
| チュートリアルの本音（「ハルの本音は？」） | `haru_profile` | 同上 |
| キズナ攻撃 | 仲間の `*_profile_kizuna`（青い横顔） | 右から左へ 0.8 秒ですべらせ、そのあと攻撃 |
| デュエットの本音（第 1 段階カナ・第 2 段階ミオ） | `kana_profile` → `mio_profile` | 段階が変わると差し替え |
| ナイトメアの体力 30% 以下（ノーマル） | ドット絵が `nightmare-reveal` に変わる（0016 で実装済み） | 立ち絵は出さない |
| 本音が届いた直後 | そのユメクイの大きい絵（img/yumekui） | 画面中央に出して、ゆっくり消す（案） |

## 3. 絆画面の立ち絵

メニューの「絆」で、キャラの横顔（`*_profile`）とそのキャラのユメクイの大きい絵を背中合わせに置く。背景はその人の夢の世界。

| キャラ | 横顔 | ユメクイ | 背景の夢 |
| --- | --- | --- | --- |
| ミオ | mio_profile | gakufume | 水底の音楽室 |
| カナ | kana_profile | togemetoro | 止まらない練習室 |
| リク | riku_profile | himawarion | ひまわり畑 |
| ハル | haru_profile | bak | 海の夢 |

絆が深まったら（キズナ攻撃が使えるようになったら）、横顔を `*_profile_kizuna` に替える（案）。

## 4. まだゲームにない場面の台本（Claude が書いた仮のセリフ）

ミチルとヒカリの口調は、キャラ設定資料に合わせた。

- **ミチル**：ゆっくりした敬語。「明日」の話をしない。夢の中では「また会いましたね」。
- **ヒカリ**：「お姉ちゃん、あのね」。句読点が少なく、一気にしゃべる。

データの形は story.js と同じで、そのまま LINES に足せる。どこで流すかは、安田が決めてから実装する。

## 5. 今ゲームにある場面の台本（story.js・mornings.js から書き出し）

- 場面の名前は LINES のキー。カッコの中は、いつ流れるか。
- 表情の列が空の行は、立ち絵が出ない話者。
- `${...}` の入るセリフ（名前や数字が入るもの）と、立ち絵の出る話者がいない場面は省いた。
