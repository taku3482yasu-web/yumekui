# ユメクイ（仮題）

他人の夢に入り、言えなかった気持ちから生まれたモンスター「ユメクイ」を仲間にしていく、ループ型のモンスター育成RPGです。

企画書: https://claude.ai/artifact/1b5QqWpwvEiTK2mwCZKNDR

## ほかのPCで作業する

リポジトリは公開（https://github.com/taku3482yasu-web/yumekui ）。Node.js（LTS）と Git があれば、どのPCでも同じように作業できます。

```
git clone https://github.com/taku3482yasu-web/yumekui.git
cd yumekui
npm install
npm run dev        # ブラウザで http://localhost:5173/
npm test           # ルールのテスト
```

作業を始める前に `git pull`、終わったら `git push` で、PCどうしの中身をそろえます。設計資料（企画書・仕様書・台本など）は Claude Docs にあります（企画書のリンクは下）。

## いま入っているもの

小規模版の途中です。「はじめる」で、青い海の砂浜に一人で立つ夢から始まります。夢がゆがんで暗くなり、大きな目が「おきろ」と言ったところで授業が終わって目が覚め、プロローグ（2月1日の放課後）になります。教室からリクと学校を出て坂道を下り、分かれ道で別れ、家で父に進路を問われ、自分の部屋でスケッチブックを見つけてキャンバスに描きます（十字キーで線を引く。何を描いても青くにじんで海のような絵になる）。ベッドで眠ると、ハルの夢へ。2月1日〜14日の昼と夜、ハルの夢、ミオとカナの単独の夢、仲間と交代、ループまで遊べます。

- 1日は 朝 → 放課後 → 夜（土日は 昼 → 夜）。平日の朝は、ハルが家の前から通学路（坂道）を校門まで歩く様子をムービーで流します。途中の3か所で立ち止まり、その日の出来事が起きます。出てくる人と話（ヒント）は、日付・周・だれを救ったか喰らったかで変わります（`src/scenes/mornings.js`）。校門に着くと朝のホームルームの出来事（3日など）のあと放課後になります
- 土日は朝が飛びます。カレンダーがめくれたあと 朝 → 昼 と時間が進み、昼に自分の部屋から始まります。玄関から外に出られます
- **夢筆**（ゆめふで）：最初の夢で、バクが筆に姿を変えて手に入ります。夢の中の光る場所で使うと、現実で見たことのある物（イメージ）を描けます。崩れた階段を描き直す（踊り場）、ピアノを描いて弾くと回復（水底の音楽室）、メトロノームを描いてテンポを落とすとナナシ・ハリが動けなくなる（止まらない練習室）。その夢に合わない物は描けません（音楽室に海は描けない）。イメージは現実で物を調べると覚えます（音楽室のピアノとメトロノーム、美術室のイーゼル、渡り廊下の手すり＝橋、坂道から見える海。学校の階段は最初から）。現実では使えません（`src/core/brush.js`・`src/data/brush.js`）
- 夢の中では、バクがハルの後ろをついて歩きます
- **夢合わせ**：拾った言葉には「前（だれと・何を）」と「後ろ（どうしたい・どうだった）」があり、メニューの「夢合わせ」で同じ人の言葉どうしをつなげて文を作ります（前＋後ろ、前＋前＋後ろ）。本音の3択には作った文が持ち込まれ、正しい文を作っていないと正解は出ません。夢には まちがいの言葉（やめたかった・くやしかった）も落ちています。チュートリアルではバクがつないで見せてくれます。前の周で言い当てた本音は最初から持っています（`src/core/sentence.js`・`src/data/words.js`）
- **夢双「ふたりのアンサンブル」**：二重奏ホールで相性を手に入れたあと、ガクフメとトゲメトロが2体ともパーティにいると、たたかうの中に出ます。威力220、哀と怒のうち相手に有利なほうの属性。使った2体はそのあと1回休み
- **夢合体『二重奏ホール』**：2周目から、2人とも元気な夜にキャンバスで「ミオ×カナの夢」を描けます（2周目の2日の朝にバクが教えてくれます）。左は水、右はトゲ。左の音の石で右の扉、右の石で左の扉が開き、奥に夢の住人（独奏の女王ミオ・審査員カナ）と言葉があります。中ボスは哀と怒が入れかわるムレスイマ。舞台のデュエット（7日から）は怒りの鳥と哀しみの鳥の2体で、片方が倒れるともう片方が怒ります。本音はカナ → ミオの順。救うと2人とも目を覚まし、ガクフメとトゲメトロが仲間になり、夢双「ふたりのアンサンブル」の相性が手に入ります
- **夢に入れる夜**：ユメクイが活性化するまでは、キャンバスに描いても夢に入れません（絵が漠然としているので、活性化して実在しているユメクイにしか夢のチャンネルが引っかからない）。小規模版では、ミオ×カナの話を最後まで進めた夜から 3 晩（進めなくても期限の 7 日には活性化するので、遅くとも 7〜9 日）です
- **ストーリーの進め方**：ミオとカナに放課後「じっくり話す」と、話が 1 段ずつ進みます（3 段、1 日 1 段）。最後の段を見ると、その夜にユメクイが活性化します。朝の通学路でもヒントが聞けます
- **夢のキャンバス**：夜、夢を選ぶと描く画面になります（十字キーで線、A で描き終える）。夢主ごとに段階 1〜5 があり、その夢に入るたびに＋1、その日に言葉を拾っていればさらに＋1。段階1 はもやで近くしか見えず、2 で地図の形、3 で敵の居場所と属性のしるし、4 で前の周にたどり着いた層から始められて本音の失敗の選択肢が1つ減り、5 で最深部から始められて本音の正解が出ます。ループでは前の周の最後の段階−1 に戻ります。二重奏ホールは2人の低いほうの段階で、差が2以上だと悪夢化（赤黒くなり、敵が1.3倍）（`src/core/canvas.js`）
- **夢感情**：仲間はみな喜・怒・哀・楽のポイントを持ち、倒した敵の属性の感情がたまります（雑魚＋2、ボス＋10、とどめは2倍、救うと喜＋5、喰らうとバクの怒＋10）。いちばん高い感情が30でステータスが傾き、60で感情技、80で気まぐれな行動、100で夢変わり（違う感情）か夢昇華（同じ感情）を聞かれます。夢変わりすると名前・属性が変わり技を覚え、その後は感情が1本になって200で夢現（バトルで1度）。育成画面に夢感情のバーがあります（`src/core/emotion.js`・`src/data/emotions.js`）
- **夢の住人**：第2層から下に独奏の女王ミオ・審査員カナがいて、下の層ほどゆがみます。深い層の住人は、まちがいの言葉（一人で・勝ちたかった）を落とします
- **完ぺきな絵と夢のかけら**：段階5まで描き上げた夢は「知っている」ことになり、次の周からは活性化の前でも入れます（合体の夢は2人とも知っているとき）。活性化前のユメクイは弱く有利に戦えますが、そのとき仲間にしたユメクイも弱いままです。前の周に救ったユメクイが時間の巻き戻りで変わった「夢のかけら」を使うと、前の周のレベルを引き継いで活性化します。活性化前に救っても、もう片方は刈り取られません
- **心のかけら**：第2〜4層に落ちていて、経験値が1.5倍になるもの（持たせる）と、本来覚えない技を覚えさせるものがあります。ループしてもなくなりません（メニューの「かけら」）
- **リクの夢『ひまわり畑』**：リクが倒れる3日から14日まで入れます（3階層＋最深部）。第1層にハルの人形と、しおれたひまわりの壁。1周目に初めて壁を調べるとナイトメアが来て、光る扉まで逃げます（捕まると「にがさない」で、その夜は失敗）。3周目、ミオとカナを救ったことがあればリクの家でリクの父から『引っ越し』を聞け、壁が開きます。奥の写真で『言えなかった』。最深部のヒマワリオン（体力が減るほど強い）の本音を当てると仲間になり、次の夜に「迷い」の場面があります
- **1周目の終わり方**：1周目だけ、ミオかカナのユメクイを倒した夜（救う・喰らうどちらでも）に、光る扉の前でナイトメア戦になります。こちらの攻撃は1しか入らず、にげられず、必ず負けます。どちらも倒さないまま9日の夜が来ると、ナイトメアのほうから部屋に来ます。負けると「に　が　さ　な　い」のあと12日まで眠り、病院で目を覚まします（本編では2週間）。残りの12〜14日は準備の期間で、夢には入れません。次の周でミオ・カナ・リクのだれを救いに行くか、町で話を聞いて決めます
- **夢を乗り越える場面**：ユメクイを仲間にするとき、夢主が自分のユメクイと話して、夢を乗り越えて送り出します（ミオ・カナ・二重奏・リク）
- **終幕（3つのエンディング）**：3周目の14日の夜で小規模版は終わり、ミオ・カナ・リクをどうしたかで分かれます
  - グッド（喰らわずに、ミオ・カナを合体で、リクも救う）：ラスボスのネムリボシに、救った仲間の「キズナ攻撃」（1人1回、守りを無視して最大体力の34%）で挑みます。ふつうの攻撃はほとんど効きません
  - ノーマル（それ以外）：ナイトメア戦。キズナ攻撃は使えず、倒すしかありません。倒すと救えなかった人のユメクイを吸って第2形態になります。リクを救ったかで最後の場面が変わります
  - ユメクイ（3人のユメクイを全部喰らう）：ナイトメアの代わりにリク・ナイトメアと戦い、そのあとラスボスをバクの専用の技「夢喰い」で喰らって終わります
  - 終幕の戦いは、負けても相手が少し弱って、もう一度挑めます。`node tools/ending-test.mjs <URL> <画像フォルダ>` で3つのエンディングを確かめられます
- **夢の階層**：ミオとカナの夢は 3 階層＋最深部、二重奏ホールは 4 階層＋最深部です。今までの地図が第 1 層で、奥の階段から下の層へ下ります。どの層も入口に毛布と光る扉があり、1 層に部屋が 3〜5 つ（右上に部屋の名前）。下の層ほど敵が強く（1 層ごとに＋15%、ボスは＋10%）、経験値も多くなります（1＋0.25×（層−1）倍）。層を下りても体力は回復しません（毛布で回復）。ボスは最深部にいます。たどり着いた層はその周のあいだ覚えていて、次の夜から「どこから はじめる？」で選べます（`src/data/layers.js`）
- **レベルとユメポイント**：戦いに勝つ（本音を届ける・喰らうも同じ）と経験値が入り、仲間はレベル1〜50で強くなります（パーティの3体はそのまま、控えは半分）。レベルはループで1に戻ります。バクだけがレベルアップでユメポイント（YP）をもらい、夢の毛布か夜のハルの部屋で、ステータス強化（1段＋5%、10段まで）とYPの技10種（ねぼけまなこ〜悪食。後半4つは救った夢・喰らった夢の数で解禁）に使えます。YPと使い道はループしても残ります。ガクフメとトゲメトロはレベル8・16・25で技を覚えます。メニューの「なかま」で育成画面を開けます（`src/core/level.js`・`src/data/growth.js`・`src/view/grow.js`）
- 戦闘の画面は2つ。始まりとコマンドを選んでいるあいだは全員を見わたす絵（仲間は前の1体を大きく、控えは後ろに小さく、敵は横に並び、ねらう敵の下に印）。技や攻撃のあいだは仲間1体とねらった敵1体（敵の攻撃のときは攻撃してきた敵）に寄って大きく映します。バクとガクフメは描いた大きい絵で出ます（`src/view/draw.js`）
- 戦闘のコマンドは たたかう・まもる・アイテム・にげる。技は たたかう の中から選びます。敵は複数のこともあり、ねらう敵を選べます。ふつうの敵からは逃げられます（ボスと最初の戦いは逃げられない）
- 戦闘に入るときは、その夢に合わせた演出のあと戦闘画面に移ります（ハルの夢はお面が迫る、ミオの夢は泡がわき上がる、カナの夢はメトロノームと迫る壁。ボスは長く、画面が揺れる）
- 時間が過ぎていく演出（町の上の空が 朝 → 昼 → 放課後 → 夕方 → 夜 と変わる）と、1日が終わると壁のカレンダーが1枚はがれて次の日になる演出があります（Aボタンで飛ばせます）
- 放課後（土日は昼）は、学校（教室・廊下・音楽室・美術室・渡り廊下）と坂道・商店街を歩いて、人に話しかけます。立ち話は何回でもでき、ミオかカナと「じっくり話す」と夕方になって家に帰ります（家の玄関に入っても帰れます）
- 画面の左上に日付と時間帯（夢の中では夢の名前）、右上に今いる場所を出します
- 夜はハルの部屋を歩けます。キャンバスを調べて描いた夢にだけ入れます。描かずに寝るか、ベッドで眠ると朝になります。玄関から夜の町へ出ることもでき、その夜は夢に入りません（夜の町には人がいません）
- 14日の夜を過ぎると、2月1日の朝に戻ります（プロローグとハルの夢はくり返しません）
- **曲と効果音**（段階5）：曲は番号（M01〜M24）で呼び、場面に合わせて自動で切り替わります（タイトル M01、夢ごとの曲、放課後 M06、夜の部屋 M07、ボスごとの曲、追われると M15、ループ M17、エンディング M20〜M22。救うと M18、喰らうと曲が止まって M19）。**音のファイルはまだ入っていないので、今は無音です。** `public/audio/bgm/M06_town.ogg`（同じ名前の `.mp3` も）のように、素材制作仕様書の名前で置けばそのまま鳴ります。効果音は `public/audio/se/SE21_hit.ogg`、セリフの声は `public/audio/voice/haru.ogg` など。名前の一覧は `src/data/sounds.js`、どの場面でどの曲かは `src/core/music.js` です。町の曲（`M06_mio` など）とノーマルED（`M21_mio` など）はパートを別のファイルで置くと、喰らった人・救えなかった人のパートが鳴らなくなります。町の曲は周回ごとにテープのようにゆれます（最終周は消える）。メニューとタイトルの「音の設定」で、曲・効果音・声の音量とホラー演出（ふつう／ひかえめ）を変えられます
- **会話の立ち絵**：会話に立ち絵を一度に2人まで出します。左が主人公の側（ハル、またはバクや救った仲間）、右が話している相手（左右反転して左向き）。地の文だけの場面では出しません。絵は `public/img/chara/<名前>_<表情>.png`（ユメクイは `public/img/yumekui/<id>.png`、夢の住人は `public/img/enemy/`）で、まだ絵の無い人（トメ・ケンなど）は出ません。11/12 の立ち絵は上が空いているので、大きめに出して頭の高さをそろえています（`src/style.css`）。セリフに3つ目を書くと表情が変わります（`['ハル', '……', 'troubled']`）。名前と絵の対応は `src/core/portraits.js`
- **土日の昼のバイト**：土日の昼、商店街のトメの駄菓子屋で「店番」か「荷運び」を手伝えます（じっくり話すと同じく1日1回、終わると夕方になって家に帰る）。お礼は駄菓子（店番1つ・荷運び2つ）で、バトルの「アイテム」で前の仲間の体力が最大の35%もどります。店番ではお客さんから、物語の進み具合に合った話が聞けます。駄菓子はループすると消えます（`src/core/job.js`）
- **夢の深い層の言葉と橋**：ミオの夢の第2層・カナの夢の第2層・二重奏ホールの第2層に裂け目があり、夢筆で「橋」（学校の渡り廊下の手すりで覚える）を描くと渡れて、奥で言葉（一緒に／相談して）を拾えます。二重奏ホールの第3層の右の譜面室にも「相談して」があります。同じ言葉を別の場所で拾っても1つです
- **演出スクリプト**（段階5）：ムービーは命令のリストとして `src/scenes/movies.js` に書き、`src/view/movie.js` で流します（絵を出す・動かす・拡大・コマ送り・揺らす・暗くする・色を抜く・字幕・文字・曲・効果音・待つ・今ある演出を呼ぶ）。決定ボタンの長押しで飛ばせ、飛ばしても最後まで見たときと同じ状態で次に進みます。2回目からは短い版（あれば）。今は「に が さ な い」をこの仕組みで流しています。MV01〜MV11 は新しいドット絵を描きながら足していきます

曲のファイル、ムービー MV01〜MV11、セーブ、仕上げはこれからです（予定は「ユメクイ 小規模版 開発スケジュール」）。

## 開発

- `npm test`: ルールと地図のテスト
- `node tools/browser-test.mjs <URL> <画像フォルダ>`: Chrome でチュートリアルを最後まで自動で遊ぶ
- `node tools/grow-shot.mjs <URL> <画像フォルダ>`: 育成画面のスクリーンショットを撮る
- セリフは `src/scenes/story.js`、夢の地図は `src/data/maps.js`、町の地図は `src/data/town.js`、数値は `src/data/units.js` にあります
- 町の決まり（人がいる日・じっくり話す・時間帯）は `src/core/town.js`、日程の定数は `src/core/days.js`
