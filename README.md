# ユメクイ（仮題）

他人の夢に入り、言えなかった気持ちから生まれたモンスター「ユメクイ」を仲間にしていく、ループ型のモンスター育成RPGです。

企画書: https://claude.ai/artifact/1b5QqWpwvEiTK2mwCZKNDR

## ほかのPCで作業する

リポジトリは公開（https://github.com/taku3482yasu-web/yumekui ）。Node.js（LTS）と Git があれば、どのPCでも同じように作業できます。

```
git clone https://github.com/taku3482yasu-web/yumekui.git
cd yumekui
npm install
npm run dev        # ブラウザで http://localhost:5173/
npm test           # ルールのテスト
```

作業を始める前に `git pull`、終わったら `git push` で、PCどうしの中身をそろえます。設計資料（企画書・仕様書・台本など）は Claude Docs にあります（企画書のリンクは下）。

## 遊び方


## いま入っているもの

小規模版の途中です。「はじめる」で、青い海の砂浜に一人で立つ夢から始まります。夢がゆがんで暗くなり、大きな目が「おきろ」と言ったところで授業が終わって目が覚め、プロローグ（2月1日の放課後）になります。教室からリクと学校を出て坂道を下り、分かれ道で別れ、家で父に進路を問われ、自分の部屋でスケッチブックを見つけてキャンバスに描きます（十字キーで線を引く。何を描いても青くにじんで海のような絵になる）。ベッドで眠ると、ハルの夢へ。2月1日〜14日の昼と夜、ハルの夢、ミオとカナの単独の夢、仲間と交代、ループまで遊べます。

- 1日は 朝 → 放課後 → 夜（土日は 昼 → 夜）。平日の朝は、ハルが家の前から通学路（坂道）を校門まで歩く様子をムービーで流します。途中の3か所で立ち止まり、その日の出来事が起きます。出てくる人と話（ヒント）は、日付・周・だれを救ったか喰らったかで変わります（`src/scenes/mornings.js`）。校門に着くと朝のホームルームの出来事（3日など）のあと放課後になります
- 土日は朝が飛びます。カレンダーがめくれたあと 朝 → 昼 と時間が進み、昼に自分の部屋から始まります。玄関から外に出られます
- **夢筆**（ゆめふで）：最初の夢で、バクが筆に姿を変えて手に入ります。夢の中の光る場所で使うと、現実で見たことのある物（イメージ）を描けます。崩れた階段を描き直す（踊り場）、ピアノを描いて弾くと回復（水底の音楽室）、メトロノームを描いてテンポを落とすとナナシ・ハリが動けなくなる（止まらない練習室）。その夢に合わない物は描けません（音楽室に海は描けない）。イメージは現実で物を調べると覚えます（音楽室のピアノとメトロノーム、美術室のイーゼル、渡り廊下の手すり＝橋、坂道から見える海。学校の階段は最初から）。現実では使えません（`src/core/brush.js`・`src/data/brush.js`）
- 夢の中では、バクがハルの後ろをついて歩きます
- **夢合わせ**：拾った言葉には「前（だれと・何を）」と「後ろ（どうしたい・どうだった）」があり、メニューの「夢合わせ」で同じ人の言葉どうしをつなげて文を作ります（前＋後ろ、前＋前＋後ろ）。本音の3択には作った文が持ち込まれ、正しい文を作っていないと正解は出ません。夢には まちがいの言葉（やめたかった・くやしかった）も落ちています。チュートリアルではバクがつないで見せてくれます。前の周で言い当てた本音は最初から持っています（`src/core/sentence.js`・`src/data/words.js`）
- **夢双「ふたりのアンサンブル」**：二重奏ホールで相性を手に入れたあと、ガクフメとトゲメトロが2体ともパーティにいると、たたかうの中に出ます。威力220、哀と怒のうち相手に有利なほうの属性。使った2体はそのあと1回休み
- **夢合体『二重奏ホール』**：2周目から、2人とも元気な夜にキャンバスで「ミオ×カナの夢」を描けます（2周目の2日の朝にバクが教えてくれます）。左は水、右はトゲ。左の音の石で右の扉、右の石で左の扉が開き、奥に夢の住人（独奏の女王ミオ・審査員カナ）と言葉があります。中ボスは哀と怒が入れかわるムレスイマ。舞台のデュエット（7日から）は怒りの鳥と哀しみの鳥の2体で、片方が倒れるともう片方が怒ります。本音はカナ → ミオの順。救うと2人とも目を覚まし、ガクフメとトゲメトロが仲間になり、夢双「ふたりのアンサンブル」の相性が手に入ります
- **レベルとユメポイント**：戦いに勝つ（本音を届ける・喰らうも同じ）と経験値が入り、仲間はレベル1〜50で強くなります（パーティの3体はそのまま、控えは半分）。レベルはループで1に戻ります。バクだけがレベルアップでユメポイント（YP）をもらい、夢の毛布か夜のハルの部屋で、ステータス強化（1段＋5%、10段まで）とYPの技10種（ねぼけまなこ〜悪食。後半4つは救った夢・喰らった夢の数で解禁）に使えます。YPと使い道はループしても残ります。ガクフメとトゲメトロはレベル8・16・25で技を覚えます。メニューの「なかま」で育成画面を開けます（`src/core/level.js`・`src/data/growth.js`・`src/view/grow.js`）
- 戦闘のコマンドは たたかう・まもる・アイテム・にげる。技は たたかう の中から選びます。敵は複数のこともあり、ねらう敵を選べます。ふつうの敵からは逃げられます（ボスと最初の戦いは逃げられない）
- 戦闘に入るときは、その夢に合わせた演出のあと戦闘画面に移ります（ハルの夢はお面が迫る、ミオの夢は泡がわき上がる、カナの夢はメトロノームと迫る壁。ボスは長く、画面が揺れる）
- 時間が過ぎていく演出（町の上の空が 朝 → 昼 → 放課後 → 夕方 → 夜 と変わる）と、1日が終わると壁のカレンダーが1枚はがれて次の日になる演出があります（Aボタンで飛ばせます）
- 放課後（土日は昼）は、学校（教室・廊下・音楽室・美術室・渡り廊下）と坂道・商店街を歩いて、人に話しかけます。立ち話は何回でもでき、ミオかカナと「じっくり話す」と夕方になって家に帰ります（家の玄関に入っても帰れます）
- 画面の左上に日付と時間帯（夢の中では夢の名前）、右上に今いる場所を出します
- 夜はハルの部屋を歩けます。キャンバスを調べて描いた夢にだけ入れます。描かずに寝るか、ベッドで眠ると朝になります。玄関から夜の町へ出ることもでき、その夜は夢に入りません（夜の町には人がいません）
- 14日の夜を過ぎると、2月1日の朝に戻ります（プロローグとハルの夢はくり返しません）

リクの夢、キャンバスの段階と悪夢化、ルート分岐はこれからです（予定は「ユメクイ 小規模版 開発スケジュール」）。

## 開発

- `npm test`: ルールと地図のテスト
- `node tools/browser-test.mjs <URL> <画像フォルダ>`: Chrome でチュートリアルを最後まで自動で遊ぶ
- `node tools/grow-shot.mjs <URL> <画像フォルダ>`: 育成画面のスクリーンショットを撮る
- セリフは `src/scenes/story.js`、夢の地図は `src/data/maps.js`、町の地図は `src/data/town.js`、数値は `src/data/units.js` にあります
- 町の決まり（人がいる日・じっくり話す・時間帯）は `src/core/town.js`、日程の定数は `src/core/days.js`
